## 对文档的改动

- **part3-core/ch14-llm-seam.md**（对应：`7e95a00c8`、`226600147`、PR #2596/#2549）
  - 14.1：`MessageSource` 的 `replayState` 类型由 `unknown` 更新为类型化 `ReplayEnvelope`，补充其结构（不透明 `response` 半区 + 可选逐块 `blocks` 条目）与设计意图；
  - 14.2：`finish` chunk 补充 `replayState?: ReplayEnvelope`；`BlockAssembler` 的 max-tokens 剪枝改为"内容与元数据一次保留/丢弃决定"（丢弃工具调用时 envelope 同步剪掉对应条目；条目数不匹配整体丢弃）；
  - 14.3：新增"回放状态读侧纪律"——不可用状态降级为提供方无关转换 + `INVALID_REPLAY_STATE` 诊断（`onReplayDegrade`），取代读取时硬错误；
  - 14.5：`llm-deepseek` 的 reasoning effort 支持 `off`/`low`/`high`/`max`（`low` 为新增）。
- **part3-core/ch16-preset-goal-subagent.md**（对应：`28fcda275`、`21d2433d9`、PR #2374）
  - 16.3：产品提供方（`subagent-codex`/`subagent-claude-code`）改为按 Profile 显式安装并在 host plane 挂载一次（生产 `dsh-base` 不再默认携带）；工具行 `backgroundMode: 'one-shot'` + 可选 `run_in_background`，后台走通用 Job 运行时；
  - 16.6：小结同步更新。
- **part3-core/ch15-capability-seams.md**（对应：`219d2a1fb`、`e00146be7`、PR #2252）
  - 15.1 表格：`ctx.attachments` 消费方扩展为 LLM 适配器、Web/ACP/MCP 图片入口、Code Mode；`ctx.jobs` 消费方增加 `tool-subagent`(one-shot bg)；
  - 15.7/15.8：补充 `AttachmentStore.saveImages()` 批次准入语义（全成员校验先于写入、整批成功才返回引用）与 Code Mode 图片转发。
- **part4-web/ch17-web-client.md**（对应：`4366528a3`、PR #2404）
  - 17.7 Slot 系统：补充 keyed slot 典型用例——`settings.plugin.item` 以 settings 命名空间为键，api-proxy 服务每个已注册命名空间，`configurable` 标签页按命名空间派发。
- **part5-plugins/ch12-tools.md**（对应：`e00146be7`、PR #2252）
  - 12.6 Code Mode：补充含图片的已结算子结果经外层 `run_code` 通用延后为带来源归属的上下文。
- **part5-plugins/ch19-plugin-patterns.md**（对应：`4366528a3`、PR #2404）
